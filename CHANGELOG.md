# Изменения

Раздел версии отсюда становится текстом релиза на GitHub
(`.github/workflows/release.yml`): заголовок раздела — `## X.Y.Z`.

## 1.0.0

Первая стабильная версия. Клиенты — Windows, Linux и Android; сервер — Linux.

**Новое**

- **Аварийное отключение на Linux** (nftables): без туннеля сеть закрыта,
  кроме локальной и исключений (`kill_switch_allow`). После краха клиента
  блокировку снимает сторож; `kill_switch_fail_closed` оставляет сеть
  закрытой до следующего запуска. На Windows — как раньше (WFP).
- **Пинг профиля** во всех клиентах: кнопка в строке профиля и «Пинг всех».
  Поднимается настоящая сессия, и через туннель уходит HTTP-запрос на
  example.com; время — от соединения до первых байтов ответа. Живое
  подключение того же профиля пинг не трогает. В консоли —
  `masquevpn-cli -ping`.
- Лицензия **MIT** (`LICENSE`); тексты лицензий стороннего кода —
  `THIRD_PARTY_NOTICES.txt`, он кладётся в установщик Windows, `.deb` и пакет
  VPS.
- Версия сборки: `vpnserver version`, `masquevpn-cli -version`, запись в
  журнале при запуске окон и сервера; в свойствах `masquevpn.exe` — 1.0.0.

**Изменено**

- Профиль сервера по умолчанию — `stock` (легенда «Caddy»): транспортные
  параметры согласованы с ServerHello. Установщик сервера переводит старые
  `cdn`/`cloudflare` сам; `cloudflare` можно выбрать явно.
- Android: номер версии (versionCode) выводится из версии (1.0.0 → 1000000) —
  APK, собранный у себя, встаёт поверх скачанного с GitHub. 1.0.0 встаёт
  поверх любой прежней версии.
- Android: отступы главного экрана и стрелка строки «Журнал» приведены к виду
  окон Windows и Linux.

**Исправлено**

- Сборка APK (`mobile/build-apk.ps1`, `build-aar.sh`) больше не оставляет
  изменёнными `go.mod` и `go.sum`.
- Тесты: гонки в `TestPolicyAccountsTraffic` под нагрузкой, устаревшее
  ожидание профиля в `TestServerFingerprintProfile`.

## 0.4.0 — 28.09.2026

- Запасные UDP-порты: сервер слушает несколько, клиент перебирает их сам и
  помнит ответивший; переход на другой порт посреди сессии.
- Сайт-прикрытие свой у каждой установки; легенда согласована с протоколом.
- Клиенты: журнал отдельным экраном, постоянная высота окна.
