# wintun.dll

Драйвер сетевого интерфейса для Windows (https://www.wintun.net), автор —
WireGuard LLC. Лежит как есть, не изменён: подпись Authenticode WireGuard
LLC внутри файла, иначе Windows не загрузит драйвер.

- `amd64/wintun.dll` — 64-битная сборка, 427 552 байта,
  SHA-256 `e5da8447dc2c320edc0fc52fa01885c103de8c118481f683643cacc3220dafce`.

Распространять неизменённую DLL вместе со своей программой разрешает
лицензия на готовые сборки Wintun (LICENSE.txt в архиве с wintun.net) — так
её и поставляют VPN-клиенты. При обновлении стоит перечитать её заново.
Обновить: скачать архив с wintun.net, взять `bin/amd64/wintun.dll`, сверить
подпись («Свойства → Цифровые подписи» — WireGuard LLC) и заменить файл.
