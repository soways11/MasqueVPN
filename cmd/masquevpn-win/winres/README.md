# Ресурсы окна Windows

Иконка и сведения о версии, встроенные в `masquevpn.exe`: их показывают
Проводник, меню «Пуск», панель задач и «Свойства → Подробно».

`rsrc_windows_amd64.syso` в каталоге выше — готовый результат, Go подхватывает
его сам при сборке под windows/amd64. Пересобрать после правки иконки или
версии:

```sh
cd cmd/masquevpn-win
go-winres make --arch amd64      # github.com/tc-hib/go-winres
```

Иконки 16–32 px нарисованы отдельно — толще линия, глубже середина: при
уменьшении общего рисунка «M» на 16 px слипалась в «H». Источник рисунка —
`deploy/linux/masquevpn.svg` (общий знак для всех систем).

Имя ресурса иконки — `APP`: по нему окно загружает её для заголовка и
панели задач (`LoadIconW(hInstance, "APP")`).
